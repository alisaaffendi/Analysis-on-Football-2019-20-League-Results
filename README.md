# Analysis-on-Football-2019-20-League-Results
This project is using Excel, to analyse team's standing during Football Premier League 2019/2020

The dataset used is given under this project, named: football team scores.csv
The analysis is done under the 'Football League Analysis.xlsm' file. This excel file is macro-enabled file. For the content:

1. Table of content
2. England 1
3. Team Position by Round
4. League Table Unsort
5. League Table Sorted
6. Team(s)

For sheet under 'Table of Content', it has overview of all contents inside the excel sheet, with hyperlinks to each respective sheet.
'England 1' sheet is the data obtained from football team scores.csv after data cleaning.
All other sheets in the excel is just summarization and visualisation of the data.
This excel uses basic VBA code (macro) as well to refresh pivot automatically.
